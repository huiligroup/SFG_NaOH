# SFG_NaOH

This repository is used to store input files and related materials for NaOH neural-network molecular dynamics simulations.

## Contents

- `NaOH_7.5M/`  
  Input files for the 7.5 M NaOH neural-network MD setup.

## Source

This repository includes the `NaOH_7.5M` directory copied from the repository:
